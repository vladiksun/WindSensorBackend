- [x] 2.4 Ensure failure logging logs the mapped exception with its original cause chain and update affected comments/docs in `ProxyService`; verify with file lint checks and `./gradlew -q compileJava`. — The `onFailure` loggers are handed the mapped exception, whose cause is still the original upstream failure; the javadoc of `clientFacing`, `fetchAndStore` and `UpstreamErrorResponseException` says which text reaches the client and which stays in the logs.
